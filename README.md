## Project Overview / Visión General del Proyecto

**Policy AI** is a SaaS platform that combines generative AI, document analysis, and real-time collaboration to simplify the creation, analysis, and modification of insurance policies.

**Policy AI** es una plataforma SaaS que combina IA generativa, análisis de documentos y colaboración en tiempo real para simplificar la creación, análisis y modificación de pólizas de seguros.

## Key Features / Características Principales

- **AI-powered policy creation** / **Creación de pólizas mediante IA**
- **Existing policy analysis** / **Análisis de pólizas existentes**
- **Visual change tracking** / **Seguimiento visual de cambios**
- **Web search integration** / **Integración con búsqueda web**
- **Intuitive UI/UX** / **UI/UX intuitiva**

## Development Timeline / Cronograma de Desarrollo

The project follows an accelerated 5-week sprint plan to deliver an MVP focused on core functionality.

El proyecto sigue un plan acelerado de sprint de 5 semanas para entregar un MVP enfocado en la funcionalidad principal.

## Technical Stack / Stack Tecnológico

- **Frontend**: Next.js, React, Tailwind CSS
- **Backend**: FastAPI (Python)
- **AI/ML**: LangChain, GPT-4/Llama 3/DeepSeek
- **Database**: PostgreSQL, Weaviate/FAISS (Opcional para vector database)
- **Infrastructure**: Docker, Cloud-based deployment
